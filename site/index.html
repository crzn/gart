До 120 учасників у грі, ваші дані у вашому акаунті Cloudflare, безкоштовний план. Встановлення займає кілька хвилин і робиться лише в браузері.

1Акаунт Cloudflare

Зареєструйтеся на dash.cloudflare.com (безкоштовно) і підтвердьте пошту. Платіжна картка не потрібна.

2Токен доступу

Відкрийте API Tokens → Create Token → Create Custom Token і додайте права:

  • Account → Workers Scripts → Edit
  • Account → D1 → Edit
  • Account → Account Settings → Read
  • для власного домену ще: Zone → Zone → Read і Zone → DNS → Edit

У «Account Resources» виберіть свій акаунт, створіть токен і скопіюйте його. Він показується один раз.

3Стартовий Worker

У Cloudflare: Workers & Pages → Create → Start with Hello World → Deploy, потім Edit code. Видаліть увесь код, вставте скрипт нижче і натисніть Deploy.

4Майстер встановлення

Відкрийте адресу цього Worker (вона виглядає як назва.ваша-частина.workers.dev). Майстер попросить токен, назву компанії та вашу пошту. Через хвилину Gart працює, і ви створюєте пароль власника.

Безпека

Security

  • Токен вводиться на сторінці, яку віддає ваш власний Worker, і йде лише до Cloudflare. Ми його не бачимо.
  • Сторінка встановлення і пакет Gart підписані ключем автора; підроблене не встановиться.
  • Пароль власника ви задаєте вже на своєму новому сайті. Він ніде не проходить транзитом.
  • Після установки токен можна видалити, а стартовий Worker прибрати. Токен потрібен лише для майбутніх оновлень з адмінки.
  • The token is typed on a page served by your own Worker and goes only to Cloudflare. We never see it.
  • The installer page and the Gart package are signed with the maintainer's key; anything forged will not install.
  • You set the owner password on your new site itself. It never passes through anything else.
  • After installation you can delete the token and the bootstrap Worker. The token is only needed for future updates from the admin panel.

FAQ

Скільки це коштує?

$0 на безкоштовному плані Cloudflare. Платні функції не вмикаються. Ліміти плану описані в документації, а вкладка «Використання» показує, скільки їх витрачено.

Де зберігаються мої дані?

У вашому акаунті Cloudflare: база D1 і Durable Objects. Автор проєкту не має до них доступу.

Установка перервалася, що робити?

Просто натисніть «Спробувати ще раз». Кроки безпечно повторювати. Якщо Worker уже створено, виберіть іншу назву або видаліть його в панелі Cloudflare.

What does it cost?

$0 on the free Cloudflare plan. No paid feature is switched on. The plan limits are described in the documentation, and the Usage tab shows how much is used.

Where is my data stored?

In your own Cloudflare account: a D1 database and Durable Objects. The maintainers have no access to it.

The installation stopped, what now?

Press “Try again”. The steps are safe to repeat. If the Worker was already created, choose another name or delete it in the Cloudflare dashboard.
