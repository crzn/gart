# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

1. Open the **Security** tab of this repository and choose **Report a vulnerability** (GitHub private vulnerability reporting).
2. Describe what you found, how to reproduce it and what an attacker could do. A short proof of concept helps.

You will get an answer within a few days. Please give us reasonable time to publish a fix before you disclose the problem. Reports about the quiz platform itself, the installer, the signed release packages and the in-app updater are all in scope.

Supported versions: the latest release only. Fixes are published as a new release; every installation can update from the admin panel (Updates tab).

How the application is protected, and the known limits, is described in [docs/SECURITY.md](docs/SECURITY.md).
